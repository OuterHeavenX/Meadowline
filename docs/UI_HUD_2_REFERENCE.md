# UI / HUD 2.0 — Owner Reference Translation

The four owner-provided images are task-local visual authority and are not committed from machine-specific attachment paths.

- Normal HUD: corner resource/date clusters, centered civic-stage badge, upper Town Goals/minimap, map dominance, contextual strip and five-action bottom dock.
- Build catalog: large warm bottom sheet, horizontal building cards, selected detail, category rail and persistent command dock.
- City Hall: tablet management surface, left navigation, strong civic header, modular truthful summary cards and visible city background.
- Main menu: live miniature city, prominent Meadowline wordmark, latest-city snapshot, Continue-first hierarchy and separate renderer/quality presentation choices.

Production differences are intentional when required by Meadowline truth. Current costs and footprints are much smaller than illustrative mockup values. Current City Hall ends at Level 4. Weather has no invented temperature. Save management exposes the real single-save action rather than a fictional slot browser. Icons reuse Meadowline's existing lightweight interface language instead of importing an unlicensed asset pack.
